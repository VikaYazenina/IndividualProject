“Персональный агрегатор контента”

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**
Объем различной информации, публикуемой в цифровом виде, растет с каждым днем. Специалистам, исследователям, людям, заинтересованным в определенной тематике или не желающим проводить время за скроллингом информации, приходится отслеживать десятки разрозненных источников. К сервисам, призванным решить эту проблему предъявляются требования: 1)поддержка множества форматов публикаций(RSS, HTML, API), 2)обеспечение базы данных под хранение полученной информации, 3)ежедневный парсинг источников с предоставлением полученных результатов. Однако, во всех имеющихся решениях отсутствует, по нашим данным: 1)возможность ручной настройки парсинга через интуитивный конструктор, 2)адаптированный под русскоговорящую аудиторию интерфейс, 3)предоставление простого персонального API для интеграции собранных данных в индивидуальные рабочие процессы. Заявляемый веб-сервис позволит решить эти проблемы и обеспечит пользователям настраиваемый и эффективный инструмент для управления информационным потоком.


**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

Программный продукт может заинтересовать широкую аудиторию, поскольку рассчитан на проведение универсальных расчётов, однако необходимо выделить несколько групп пользователей, для которых существует свой тип настроек (профилей). Эти настройки будут влиять на функционал и интерфейс(внешний вид), тарифный план и возможность экспортировать результаты вычислений. К выделяемым группам относятся:

* Молодые ученые, студенты в возрасте 22-30 лет
* Активные спортивные фанаты(в основном инфлюенсеры, строящие свой контент на спортивной тематике) в возрасте от 14 до 25 лет
* Преподаватели вузов и научные сотрудники

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]** 

Продукт разрабатывается исключительно как веб-сервис под:

* актуальные версии браузеров(Google Chrome, Safari, Mozilla Firefox и т.д.)
* устройства с доступом в интернет(ПК, смартфон, планшет и т.д.)
**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

Программный продукт будет предоставлять следующие возможности:
* Управление источниками сбора информации
* Автоматический парсинг и сбор данных
* Функция отложенного прочтения 
* Расширенный поиск и фильтрация данных в веб-архиве
* Система категорий/тэгов для источников
* Формирование ежедневной рассылки с новыми материалами
* Хранение данных в веб-архиве
* Экспорт результатов в различные форматы 
* Аналитика потребления
**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

Анализ 2 программных продуктов, которые максимально приближены к заданному функционалу, показал, что:

* Feedly: не предоставляет инструментов для ручного парсинга сайтов без RSS, премиум-функции и имеют высокую стоимость
*	Inoreader: интерфейс перегружен для новичков, бесплатный тариф сильно ограничен
