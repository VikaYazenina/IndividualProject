### [ Сценарий 1 - Добавление RSS-источника ]

1. Пользователь нажимает кнопку "Добавить новый источник". 
2. Пользователь выбирает тип источника "RSS/Atom лента".
3. Пользователь вводит URL RSS-ленты.
4. Система проверяет валидность URL и доступность. 
4.1. В негативном случае: система показывает сообщение "Указанный URL не является валидной RSS-лентой".
5. Система автоматически извлекает название источника.
6. Пользователю всплывает окно с названием источника.
7. Пользователь нажимает кнопку "Сохранить источник".
8. Система добавляет источник в список и запускает сбор первичных статей.

### [ Сценарий 2 - Анализ активности ]

1. Пользователь переходит в раздел "Статистика"
2. Система отображает график "Статей собрано за последние 30 дней".
2.1. В негативном случае: система показывает сообщение "Недостаточно данных для статистики".
3. Пользователь видит количество статей.
4. Система показывает диаграмму "Распределение по категориям".
5. Система отображает список "Топ-5 самых активных источникоа".
6. Пользователь видит, сколько статей предоставили топ-5.
7. Пользователь нажимает кнопку "Экспорт статистики в PDF".
8. Система генерирует и скачивает отчет в формате PDF.


### [ Сценарий 3 - Добавление веб-сайта без RSS]

1. Пользователь нажимает кнопку "Добавить новый источник". 
2. Пользователь выбирает тип источника "Веб-сайт(HTML)".
3. Пользователь вводит URL онлайн-страницы.
4. Система проверяет валидность URL и доступность. 
4.1. В негативном случае: система показывает сообщение "Указанный URL не является валидным".
5. Пользователь нажимает кнопку "Проанализировать структуру".
6. Система загружает страницу и предлагает выбрать CSS-селектор.
7. Пользователь выбирает селектор из предложенных вариантов.
8. Система автоматически предлагает селекторы для заголовка, даты, ссылки и т.п.
9. Пользователь проверяет корректность предложений.
10. Пользователь нажимает кнопку "Сохранить источник".
11. Система добавляет источник в список и запускает сбор первичных статей.

### [ Сценарий 4 - Создание персональной категории источников ]

1. Пользователь переходит в раздел "Категории".
2. Пользователь нажимает кнопку "Создать новую категорию".
3. Пользователь вводит название новой категории.
4. Пользователь нажимает кнопку "Сохранить новую категорию".
5. Система добавляет новую категорию в общий список.
6. Пользователь переходит в раздел "Мои источники".
7. Пользователь выбирает n-ное количество источников из списка.
8. Пользователь нажимает кнопку "Изменить категорию" в меню действий.
9. Пользователь выбирает из выпадающего списка недавно добавленную категорию.
10. Система применяет изменения ко всем выбранным источникам.

### [ Сценарий 5 - Запуск принудительного сбора материалов ]

1. Пользователь находится в разделе "Мои источники".
2. Пользователь нажимает кнопку "Запустить сбор сейчас".
3. Система показывает окно с подтверждением.
4. Пользователь подтверждает действие кнопкой "Начать сбор".
5. Система запускает фоновый процесс сбора.
6. Система отображает прогресс-бар и количество обработанных источников.
7. По завершении система показывает окно "Сбор завершен".
8. Пользователь видит количество новых статей, добавленных в архив.
9. Пользователь переходит в раздел "Архив", чтобы посмотреть новые материалы.

### [ Сценарий 6 -  Поиск статей в архиве по ключевым словам]

1. Пользователь переходит в раздел "Архив".
2. Пользователь нажимает на поле поиска в верхней части страницы.
3. Пользователь вводит ключевые слова.
4. Пользователь нажимает клавишу Enter или кнопку "Найти".
5. Система выполняет поиск по заголовкам и описаниям статей.
6. Система отображает список из n-ных найденных статей.
6.1. В негативном случае: система показывает сообщение "По вашему запросу ничего не найдено".
7. Пользователь применяет фильтр "Только за последний месяц".
8. Система фильтрует результаты поиска.
8.1. В негативном случае: система показывает сообщение "По вашему запросу ничего не найдено".
9. Пользователь кликает на заголовок статьи, чтобы открыть ее в новой вкладке.

### [ Сценарий 7 -  Экспорт подборки статей]

1. Пользователь переходит в раздел "Архив".
2. Пользователь помечает галочками n-ное количество статей.
3. Пользователь нажимает кнопку "Экспорт выбранного".
4. Система выбирает окно с выбором формата.
5. Пользователь выбирает формат.
6. Система предлагает выбрать поля для экспорта.
7. Пользователь выбирает из "Заголовок","Ссылка","Дата","Источник" и т.п.
7. Пользователь нажимает кнопку "Сформировать файл".
8. Система генерирует файл в фоновом режиме.
9. Система автоматически скачивает файл.

### [ Сценарий 8 -  Формирование рассылки email-дайджеста]

1. Пользователь переходит в раздел "Настройки"->"Рассылки".
2. Пользователь находит блок "Ежедневный дайджест".
3. Пользователь включает переключатель "Включить email-рассылки".
4. Пользователь выбирает время отправки из выпадающего списка.
5. Пользователь выбирает часовой пояс из выпадающего списка.
6. Пользователь включает переключатель "Иметь функцию отложенного прочтения".
7. Пользователь устанавливает лимит на количество статей в день.
8. Пользователь нажимает кнопку "Сохранить настройки".
9. Система показывает сообщение "Настройки сохранены".
